# Archived changes

Every change that shipped, with the argument that produced it: the proposal, the
design, the tasks, and the spec delta it merged into `openspec/specs/`.

**These are historical documents.** They describe what was proposed at the time,
including alternatives that were rejected and constraints that have since moved.
Where one disagrees with the code, the code is right and this is the record of
how it got there.

The current behaviour contract is [`openspec/specs/`](../../specs/) — sixteen
capabilities, kept in step with the code by `make specs`. Read that to find out
what remedik does. Read these to find out why, and what was tried instead.

Anything in `openspec/changes/` that is *not* in here is proposed and not built.
