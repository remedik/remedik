# Screenshots

Taken from a real cluster with `hack/screenshots.sh`, not mocked up. The
data is a development cluster, so the numbers are small and the failures are
deliberate — a remediation targeting a Deployment that does not exist, so
the escalation path has something to report.

Regenerate them after any change to the dashboard's markup or stylesheet.
A screenshot that no longer matches the product is worse than none, and it
is the first thing anybody looks at.
